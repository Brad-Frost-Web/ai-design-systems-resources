  ahead of time? I’ve been thinking about that a lot while working on some
  StoryUI updates. StoryUI already has a Voice Canvas where you can dictate what
  you want and watch the interface update in real time. Until now, all of that
  went through an LLM. But a lot of these edits don’t really need one. “Change
  the title to this.” “Make the button blue.” “Check that checkbox.” “Add
  another text input.” These are decisions against a known set of components,
  properties, and values. That’s exactly what Jev is good at. So I added Jev to
  the V"
