Brad puts branching to work. The AI-generated animations feel cramped, so he drops a screenshot into Claude Code and asks it to create an illustration-animation branch and make the demos full width. Claude does both; the refreshed page is far more legible, and GitHub Desktop confirms a single changed stylesheet on the new branch, main untouched. Notes that branching is what makes it safe to experiment while main could be auto-deploying via a tool like Netlify, then commits the styles.
