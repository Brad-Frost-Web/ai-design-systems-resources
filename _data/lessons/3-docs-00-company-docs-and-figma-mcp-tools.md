TJ introduces an agentic documentation workflow: generating machine-readable docs straight from Figma using the Figma Console MCP's Generate Docs tool (which captures component descriptions, properties, and annotations into markdown), plus Company Docs, a custom MCP that connects documentation to any MCP client like Claude, Cursor, Slack, Replit, or Lovable. An open skills repository offers the same capabilities for teams limited to Figma's native MCP.
