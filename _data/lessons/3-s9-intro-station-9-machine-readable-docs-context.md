Introduces Station 9, the first of two AI-readiness stations: machine-readable docs and context. The check engine light is on when documentation, code, and usage guidelines all exist but there's no explicit AI-facing context surface, so agents misuse components. LLMs can evaluate how AI-ready your docs and component metadata are, then help generate machine-readable metadata — with the caveat that these tools and techniques are emerging and changing constantly.
