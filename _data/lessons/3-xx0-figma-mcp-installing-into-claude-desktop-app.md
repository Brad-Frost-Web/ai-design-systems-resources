Walks through adding the official Figma MCP connector to the Claude Desktop app — installing it via the in‑chat plus menu → Connectors → Manage connectors → Browse → Figma → Install, enabling the Desktop MCP server inside Figma's dev mode, restarting Claude so the tools load, and verifying with 'what component am I on in Figma?' to get back the slpl‑text‑field metadata in both Claude chat and Claude Code.
