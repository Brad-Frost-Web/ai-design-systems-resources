Recaps Station 9: "docs exist" (covered back in Station 1) is not the same as "a machine can actually pick up those docs and use them properly." Getting there requires iteration — having AI generate compositions, recipes, components, and full pages to see where it trips up, then feeding that back to strengthen the machine-readable documentation — while remembering these formats and techniques are still evolving alongside the AI models themselves.
