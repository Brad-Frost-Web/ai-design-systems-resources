TJ walks through Company Docs, an open-source custom MCP built on a Cloudflare worker with a Supabase vector database that ingests markdown plus HTML, PDFs, and live URLs. He connects it to Claude as a connector at eventz-docs-mcp.southleft-llc.workers.dev/mcp with four search-and-retrieval tools, queries text area docs and tag token specs, and notes you can plug it into Lovable, Replit, or v0 to generate UI grounded in your design system documentation.
