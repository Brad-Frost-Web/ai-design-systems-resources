TJ demos a DS component eval skill in Claude Code that runs a repeatable accessibility and design system QA evaluation on a chip component set via the Figma Console MCP, combining deterministic Python-scripted checks with LLM-as-judge feedback from the Design Systems Assistant MCP. The eval scores the component 81.4 out of 100, flagging a missing focus state and state coverage gaps weighed against WCAG.
