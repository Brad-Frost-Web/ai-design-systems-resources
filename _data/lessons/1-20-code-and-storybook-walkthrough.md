Hands‑on tour of Storybook: the UI, component navigation, component preview, show/hide code, props (label, onClick, primary), controls and variants, button.stories files, authoring a new story, and the add‑ons panel (actions, interaction testing, visual tests, accessibility checks). Then explains how design tokens are layered in via Style Dictionary and JSON (platform‑agnostic output to web CSS custom properties, iOS, Android, etc.), shown in the Subatomic token system and Eddie / Altitude / Carbon / GOV.UK Storybooks. Sets up the next step: packaging the library for downstream teams.
