TJ has Claude Code develop the chip component as a Storybook component with stories, then invokes the Playwright MCP to enter a self-healing loop that screenshots, reviews, and fixes the component in a background browser — verifying markup, tokens, keyboard focus rings, selectable toggle, and dismiss behavior, running axe accessibility scans (zero violations, 20 passes), and fixing the focus indicator eval blocker for Figma-to-code parity.
