End‑to‑end demo of translating the AI‑ready Soul Patrol text field component from Figma into code via the Figma MCP and Claude Code. Claude pulls Figma metadata, surveys the existing Lit web component library (text-area, checkbox patterns) to align with house conventions, generates the .ts component file, SCSS, Storybook stories, and a Playwright unit test directory — and even invents an inverted variant by extrapolating from neighboring form fields. Lands a working text field in Storybook using the right design tokens (color/content/utility/error etc.).
