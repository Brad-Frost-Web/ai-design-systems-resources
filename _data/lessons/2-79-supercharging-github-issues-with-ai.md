Brad asks Claude Code to file two issues at once: one in learning-git to adopt the Eddie design system, and one in the Eddie repo asking it to crawl this site and flag gaps that would block adoption. With GitHub CLI, the Eddie Brain MCP, and both repos in reach, Claude files both, cross-linked, with context and acceptance criteria — and the Eddie issue surfaces real gaps (a segmented control, a required hero image, illustration primitives). Contrasts this with the paragraph-long issues of traditional design system workflows, notes non-coders can use the same access to ask questions of a codebase, and confesses this workflow cured his own Git imposter syndrome.
