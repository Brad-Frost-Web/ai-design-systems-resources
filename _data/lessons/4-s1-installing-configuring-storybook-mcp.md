TJ installs the Storybook MCP into the College Town codebase, advising against delegating the install to an agent because the commands are interactive. Runs the npx add-on install, then explains the mcp add command: HTTP transport, the Storybook URL on port 6006 (adjust if you run several instances), and project-level scope rather than global or user. Answers the prompts — a project-specific server name, no HTTP headers, Claude Code as the client, no OAuth client ID — and leaves it ready to run.
