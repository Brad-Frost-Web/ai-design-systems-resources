A machine-readable definition of a component (its props, variants, states, slots, token references, and constraints) written as plain data like JSON or YAML, independent of any one framework or design tool. Because the contract is the agreement about what a component is, Figma and code can both be generated from it or checked against it, and agents can validate their output against it instead of guessing from code. A recurring jam session topic, and one of the community's main answers to drift.
