An open format from Google Labs (popularized by its Stitch tool) for describing a visual identity to coding agents: a Markdown file pairing machine-readable design tokens with plain-language rationale. It plays a role for visual design similar to the one AGENTS.md plays for engineering conventions. Useful lightweight context, but no substitute for an actual design system of components.
