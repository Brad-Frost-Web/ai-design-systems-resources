Producing or checking output with fixed rules and scripts rather than a model, so the same input always gives the same result. Translating a component contract into code or Figma, or running accessibility, unit, and visual-regression checks in CI, are deterministic. The course's stance is to use AI to build deterministic tools wherever possible, reserving the model for the parts that genuinely need judgment. See Non-Determinism.
