A form of user experience in which interfaces shift from fixed, settled things into fluid, dynamic, generated experiences. Chapter 5 describes three flavors: interfaces composed on the fly from the design system's own components, bespoke code generated for the moment, and output that goes straight to pixels. The first keeps generated UI on the rails, and protocols like A2UI make it concrete by having agents pick from a catalog of approved components. See also Hyperpersonalization.
