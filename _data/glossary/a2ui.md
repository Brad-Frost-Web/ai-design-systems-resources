An open protocol, originally from Google, in which an agent describes an interface as declarative data and the client renders it from a catalog of pre-approved components. Your design system is the catalog: the agent picks the right pattern for a request (a timeline, a chart, a card grid) without writing arbitrary code. One of the concrete forms generative UI is taking.
