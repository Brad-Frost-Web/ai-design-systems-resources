A structured map of a design system's real components, props, slots, tokens, and their relationships, generated from source rather than written by hand. An MCP server answers agents' questions from the graph, so they look up what exists instead of guessing. The course's Eddie demos keep the graph in sync with the code so it never becomes a source of drift itself.
